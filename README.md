# Saved RPG
Still in development--
Play NOW! [Saved RPG](https://saved-rpg.vercel.app/)

## Details
This project is designed to be a way to keep my programming and web dev alive. To keep me accountable to practice creating things, to learn art, to be passionate about working my mind.
The very first thing I found when I started teaching myself to code was text based games, which I found great success in and sank hundreds of hours into creating. Each stage of my programming
career I went back and remade my text based games in all of the different languages and game engines that I had practiced.
